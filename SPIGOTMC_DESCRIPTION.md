# LuckRank

**LuckRank** is a clean and lightweight rank management plugin for **LuckPerms**, built for servers that want fast workflows, simple commands, and clear team communication.

It helps staff manage ranks, permissions, group creation, and notifications without unnecessary complexity.

## Why LuckRank?

- Clean and focused command system
- Fast rank management directly in-game
- Temporary and permanent rank support
- Permission editing for players and groups
- Group creation from in-game commands
- Staff notification system
- Discord webhook support
- Update notifications for new releases
- Separate Spigot and Bungee modules

## Features

### Rank Management
- Set ranks for online players
- Remove ranks with confirmation protection
- Support for permanent and timed ranks

### Permission Management
- Set permissions for players
- Set permissions for groups
- Clear permission-based control for staff

### Group Tools
- Create new LuckPerms groups in-game
- Set weight and display name while creating groups

### Staff Workflow
- Optional notification toggle for staff members
- Broadcast important rank actions to authorized team members
- Discord webhook integration for logging important actions

## Commands

- `/rank set <player> <rank> <duration>`
- `/rank remove <player> <rank>`
- `/rank setperms <player|group> <permission> <true|false>`
- `/rank creategroup <name> <weight> <displayname>`
- `/rank notify`
- `/rank debug`

## Perfect For

- Survival servers
- Citybuild servers
- PvP servers
- Minigame networks
- Staff teams using LuckPerms

## Requirements

- LuckPerms
- Java 8 or higher

## Notes

LuckRank is designed to stay simple, practical, and easy to maintain.

If you want a rank tool that focuses on real server workflows instead of bloated menus and unnecessary extras, this plugin is built for you.
